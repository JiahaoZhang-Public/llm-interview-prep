# P006 RoPE Position Embedding 题解

## 核心思路

1. 把每个维度对 (d_{2i}, d_{2i+1}) 视为一个 2D 向量
2. 对位置 m，用频率 θ_i = base^{-2i/d} 计算旋转角度 mθ_i
3. 对 Q 和 K 的每对维度施加 2D 旋转：[cos(mθ), -sin(mθ); sin(mθ), cos(mθ)]
4. 旋转后 Q·K 的点积自然包含相对位置信息

## 面试口述模板

> "RoPE 的核心思想是用旋转矩阵编码位置信息。
> 把向量的每两个相邻维度看作一个 2D 平面，
> 根据位置 m 和频率 θ_i = base^{-2i/d} 计算旋转角度 mθ_i，
> 对 Q 和 K 的每个维度对做旋转。
> 关键优势：旋转后 Q 和 K 的点积只依赖于相对位置差，
> 天然编码了相对位置信息，且可以通过 NTK-aware scaling 做长度外推。"

## 常见坑

- **频率计算**：θ_i = 1 / (base^{2i/d})，不要把指数搞反
- **旋转方向**：(x1, x2) → (x1·cos - x2·sin, x1·sin + x2·cos)，正弦余弦的正负号不能弄混
- **只对 Q 和 K 旋转**：V 不需要 RoPE，因为位置信息已经编码在 attention weights 里了
- **维度奇偶配对**：实现时 x[..., 0::2] 和 x[..., 1::2] 要正确配对

## 复杂度

- 时间：O(n · d)，对每个位置的每个维度对做旋转
- 空间：O(n · d) 存 cos/sin 表（可预计算）
- 比可学习的绝对位置编码更高效，且天然支持变长序列
