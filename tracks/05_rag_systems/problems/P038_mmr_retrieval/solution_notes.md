# P038 MMR Retrieval 题解

## 核心思路

1. MMR（Maximal Marginal Relevance）在检索时平衡相关性和多样性
2. 公式：MMR = argmax_{d∈R\S} [λ · sim(d, q) - (1-λ) · max_{d'∈S} sim(d, d')]
3. 贪心迭代：每轮从候选集中选一个 MMR 分数最高的文档加入结果集 S
4. λ 接近 1 退化为纯相关性排序，λ 接近 0 则最大化多样性
5. 实现步骤：先用余弦相似度检索 top-N 候选，再在候选集上跑 MMR 贪心选 top-k

## 面试口述模板

> "MMR 的核心是贪心选择。我先检索出一个较大的候选集（比如 top-20），然后迭代 k 轮。每轮对候选集中每个未选文档计算两个分数：和 query 的相似度乘以 λ，减去和已选文档集中最相似文档的相似度乘以 (1-λ)。选 MMR 得分最高的加入结果集。这样每选一个新文档都考虑了它和已选文档的冗余度，保证结果既相关又多样。"

## 常见坑

- **λ 的取值**：面试中常问 λ 的含义和调参策略，要能解释 trade-off
- **候选集太小**：如果候选集 = k，MMR 退化为普通排序，需要候选集 >> k
- **相似度矩阵预计算**：候选文档两两相似度可以预先算好，避免重复计算
- **第一个文档**：第一轮 S 为空，max 项为 0，直接选最相关的文档

## 复杂度

- 时间：O(k · N · d)，k 轮迭代，每轮遍历 N 个候选并计算与已选集的相似度
- 空间：O(N²) 若预计算候选间相似度矩阵，否则 O(N·d)
