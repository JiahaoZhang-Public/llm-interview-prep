# P012 WordPiece Tokenizer 题解

## 核心思路

1. 给定一个已有的 vocab 字典（token → id），对输入文本做贪心最长匹配分词
2. 对每个单词，从左到右尝试匹配 vocab 中最长的子串
3. 非首子串加 `##` 前缀（表示词内连续）
4. 如果任何子串都匹配不到，整个词标为 `[UNK]`

## 面试口述模板

> "WordPiece 是 BERT 使用的分词算法，核心是贪心最长匹配。
> 对每个单词，从左边开始尝试匹配 vocab 中最长的子串，
> 第二个及之后的子串加 `##` 前缀表示是词内续接。
> 如果找不到匹配就输出 `[UNK]`。
> 和 BPE 的区别：BPE 通过合并频率最高的 pair 自底向上构建，
> WordPiece 通过最大化训练似然选择合并——但编码阶段都是贪心匹配。"

## 常见坑

- **`##` 前缀处理**：只有非首子串需要加 `##`，首子串直接匹配
- **贪心方向**：从左到右，每次取最长匹配
- **UNK 回退**：任何子串匹配不到时整个词变 UNK，不是只把那个字符变 UNK
- **decode 时去掉 `##`**：还原时 `##` 前缀的 token 直接拼接，不加空格

## 复杂度

- 编码：O(L²) 每个词，L 为词长（贪心匹配每步最多回退 L 次）
- 空间：O(V) 存 vocab
