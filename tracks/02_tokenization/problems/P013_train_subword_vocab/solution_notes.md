# P013 Train Subword Vocab 题解

## 核心思路

1. 初始词表 = 语料中所有单字符
2. 反复统计语料中最高频的相邻 pair
3. 合并该 pair 为新 token，加入词表
4. 重复直到 vocab_size 达标
5. 返回 token → id 的字典

这本质就是 BPE 训练过程的抽象。

## 面试口述模板

> "训练 subword vocab 的核心算法是 BPE：
> 从单字符词表开始，反复找语料中出现次数最多的相邻 token pair，
> 把它们合并为一个新 token 加入词表，直到词表达到目标大小。
> 这是一个贪心算法，每步选局部最优合并。
> 最终词表兼顾了常见词（合并为完整 token）和罕见词（保留字符级粒度）。"

## 常见坑

- **初始词表要排序**：保证确定性，方便复现
- **合并后要更新所有词的表示**：不能只统计不替换
- **停止条件**：vocab_size 包含初始字符，可能合并次数 < 预期

## 复杂度

- 时间：O(V × N × L)，每轮合并都要扫描所有词
- 实际用 priority queue 可以加速到 O(V × L × log N)
