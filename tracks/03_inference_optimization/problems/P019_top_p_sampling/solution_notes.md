# P019 Top-P (Nucleus) Sampling 题解

## 核心思路

1. 对 logits 做 softmax 得到概率
2. 按概率从大到小排序
3. 累加概率直到总和 ≥ p，这些 token 构成 "nucleus"
4. 在 nucleus 内重新归一化后随机采样

Top-P 的候选集大小是动态的，根据分布形状自适应。

## 面试口述模板

> "Top-P sampling 也叫 nucleus sampling。它不像 Top-K 固定候选数量，
> 而是按概率从高到低累加，直到累计概率达到阈值 p（比如 0.9），
> 把这些 token 作为候选集。这样当分布很尖锐时候选很少（接近 greedy），
> 分布很平坦时候选很多（保留多样性），比固定 K 更灵活。
> p=1.0 等价于全分布采样，p 趋近 0 等价于 greedy。"

## 常见坑

- **累加方向**：必须从概率最高的开始累加，不是从最低的
- **边界处理**：累计刚好等于 p 时那个 token 要不要包含——标准做法是包含（≥ p 时停止）
- **重新归一化**：nucleus 内的概率之和可能 > p，采样前要重新归一化到 1
- **和 Top-K 组合使用**：实际系统经常 Top-K + Top-P 一起用，先 Top-K 截断再 Top-P 过滤

## 复杂度

- 时间：O(V log V) 排序
- 空间：O(V)
- 实际 nucleus 大小通常远小于 V，采样部分很快
