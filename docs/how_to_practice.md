# 如何刷这个仓库

## 推荐节奏

1. 先按 track 读 `concepts/overview.md`
2. 再做对应题目的 `starter.py`
3. 写完后运行该题的 `test_public.py`
4. 最后看 `followups.md`，补上面试追问

## 一次刷题的最小闭环

- 先自己写 20-40 分钟
- 卡住时只允许回看知识卡片，不直接看答案
- 用 public tests 检查边界
- 最后用 3 分钟口头复述：题意、接口、复杂度、边界条件

## 分支使用方式

- 题面练习请在 `codex/zh-cn` 或 `codex/en-us`
- 参考答案只在 solutions 分支查看
- `main` 只作为代码和测试同步基线
